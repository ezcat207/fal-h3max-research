# 候选场景对比：4 个「假设 + 验证实验」一页纸

> 承接 `lean-spec.md`。目的：在**不预先定方向**的前提下，把 4 个候选场景放到同一张模板下横向比较，用「最危险假设 + 最便宜实验」的方式，帮你决定 Cycle 2 先押哪一个。
> 版本：v0.1 ｜ 2026-09-04 ｜ 状态：**候选阶段（全部未验证）**

**评分维度**（1–5，越高越好）：
- **需求/付费意愿**：痛点有多痛、掏钱有多爽快
- **差异化空间**：赛道拥挤度的反向（越不拥挤越高）
- **独占分发**：能否拿到边际成本递减、别人抢不走的获客渠道
- **单元经济**：定价 − COGS − 获客后的毛利健康度
- **抗后端吃掉**：FAL/实验室向下爬栈时，我们的独占层有多硬
- **启动可行性**：我们（小团队/单人）能否 4–6 周内跑出第一个实验

---

## 场景 A · 电商 SKU → 批量投放广告视频（B2B SaaS）

**一句话**：接入商家的商品 feed，自动把每个 SKU 批量产出「可直接投放、按平台规格切好」的短视频广告，并回灌投放数据做迭代。

| 项 | 内容 |
|---|---|
| **目标用户（窄 ICP）** | 月广告花费 $5k–50k 的 DTC/独立站卖家 & 中小投放代理（Shopify/TikTok Shop 生态） |
| **痛点 & 现状替代** | 素材是投放瓶颈；现状=外包剪辑（贵/慢）或 Arcads/Creatify（通用、不接 feed、不闭环数据） |
| **价值假设 VH** | 让「每个 SKU 的可投广告」制作成本从 $30–100/条 降到 &lt;$3、时间从数小时降到分钟级，且 CTR/CVR 不低于人工素材 |
| **商业假设 BH** | 按「产出条数 + 投放效果」收费（$99–499/月 + 用量），毛利靠工作流而非转售秒数；LTV/CAC≥3 |
| **独占层/护城河** | ①与商品 feed / 广告后台的深度集成 ②**投放效果数据飞轮**（哪种脚本/画面转化高）③模板与合规（品类广告规范） |
| **最危险假设** | **A1**：商家愿为「成片可投 + 效果闭环」付费，而不是满足于自己用 FAL 免费额度拼 |
| **最便宜实验** | 假门落地页（收集 15 个目标商家邮箱/预付）+ 对 5 家做 concierge：人肉用 FAL API 帮他们把 20 个 SKU 做成广告，投一周看数据 |
| **成功阈值** | 5 家里 ≥3 家愿意继续付费；对比其现有素材，CTR 不降且制作成本降 ≥80% |
| **周期** | 4 周 |
| **主要风险** | ①赛道已拥挤（Icon/Arcads/Creatify）②Shopify/TikTok 自带 AI 素材功能会挤压 ③FAL 客户 Hedra/Poe 上游即可做 |
| **谁已在做** | Icon、Arcads、Creatify、CreateUGC、LTX Studio |

**评分**：需求 5 ｜ 差异化 2 ｜ 独占分发 3 ｜ 单元经济 4 ｜ 抗吃掉 3 ｜ 可行性 3 → **加权 3.4**

## 场景 B · Faceless 频道内容工厂（面向创作者/单干者）

**一句话**：一键把「选题 → 脚本 → 配音 → 画面 → 字幕 → 定时发布」自动化，让单人运营多个 faceless 短视频/Shorts 频道。

| 项 | 内容 |
|---|---|
| **目标用户（窄 ICP）** | 想做副业/矩阵号的个人创作者、想跑内容矩阵的小工作室 |
| **痛点 & 现状替代** | 日更太累、跨工具拼装繁琐；现状=Faceless.so/Syllaby/InVideo + 一堆 Gumroad 教程 |
| **价值假设 VH** | 让单人可稳定运营 3–5 个频道、日更不崩，且成片过审率/完播率达标 |
| **商业假设 BH** | 订阅制（$29–99/月）+ 用量；难点=留存（内容号生死无常，用户流失快） |
| **独占层/护城河** | ①选题/爆款数据（什么题材在涨）②发布矩阵与账号管理 ③社区/教程飞轮（内容创业者聚集） |
| **最危险假设** | **A3**：CAC 可控——能靠内容/社区（而非纯投放）低成本获客；否则在红海里烧钱必死 |
| **最便宜实验** | 自己先用工作流跑 2 个真频道 4 周（既验证产品也做获客内容）；同时一条内容渠道（YouTube/小红书教程）看获客成本 |
| **成功阈值** | 频道有真实自然增长（非刷）；内容渠道 CAC ≤ 目标 LTV/3；≥30 个候选用户进 waitlist |
| **周期** | 4–6 周 |
| **主要风险** | ①极度拥挤 + 低客单价 + 高流失 ②平台反 AI 内容政策 ③价值以「slop」为主，护城河薄 |
| **谁已在做** | Faceless.so、Syllaby、InVideo AI、VideoBytes + 大量教程卖家 |

**评分**：需求 4 ｜ 差异化 2 ｜ 独占分发 3 ｜ 单元经济 2 ｜ 抗吃掉 2 ｜ 可行性 5 → **加权 2.9**

## 场景 C · 虚拟人口播 / 数字人 SaaS（B2B）

**一句话**：把一段脚本/一张形象，变成「品牌数字人口播视频」，用于产品讲解、客服、培训、多语本地化。

| 项 | 内容 |
|---|---|
| **目标用户（窄 ICP）** | 需要规模化口播的 B2B（SaaS 产品讲解、跨境多语本地化、企业培训/HR） |
| **痛点 & 现状替代** | 真人拍摄贵/难改；现状=HeyGen/Synthesia/Hedra/Captions（通用、贵、口型/一致性参差） |
| **价值假设 VH** | 让「脚本改一版 → 重出视频」成本≈0、支持多语一致形象、口型/情绪达到可用；替代真人拍摄 |
| **商业假设 BH** | 席位 + 分钟数订阅（$49–299/月）；B2B 客单价高、留存好，是 4 个里单元经济最健康的 |
| **独占层/护城河** | ①企业形象/品牌资产库 + 合规授权 ②与培训/CRM/文档系统集成 ③垂直模板（如金融/医疗合规话术） |
| **最危险假设** | **A4 + A2**：在**我们选的具体场景**里，质量（口型/一致性/768p）够用到愿意替代真人 |
| **最便宜实验** | 选 1 个垂直（如 SaaS 产品讲解），对 5 家 concierge：人肉产出他们的口播视频，让他们盲评「能不能直接用」 |
| **成功阈值** | 成片可用率 ≥60%；≥3 家愿付费；相比现方案时间降 ≥70% |
| **周期** | 4–6 周 |
| **主要风险** | ①HeyGen/Synthesia 已是强品牌②口型/一致性是硬门槛，H3 Max 砍了部分音频特性③需拼多个模型 |
| **谁已在做** | HeyGen、Synthesia、Hedra（Character-3，且是 FAL 客户）、Captions |

**评分**：需求 4 ｜ 差异化 3 ｜ 独占分发 3 ｜ 单元经济 5 ｜ 抗吃掉 3 ｜ 可行性 3 → **加权 3.5**

## 场景 D · 垂直本地商家营销视频（如餐饮/地产/健身/门店）

**一句话**：给某个**具体垂直**的本地商家，做「拍张照/填个信息 → 出一条本地感的营销/探店/带看短视频 → 一键发到大众点评/小红书/抖音本地」的傻瓜工具。

| 项 | 内容 |
|---|---|
| **目标用户（窄 ICP）** | 先只做**一个**垂直（例：独立餐饮门店 或 房产经纪 或 健身工作室） |
| **痛点 & 现状替代** | 不会剪、没时间、通用工具太复杂；现状=找本地 MCN/代运营（贵）或干脆不做 |
| **价值假设 VH** | 让完全不懂剪辑的老板，5 分钟出一条「像模像样、有本地味」的短视频并发出去，带来到店/咨询 |
| **商业假设 BH** | 低月费订阅 + 按条；或与本地服务商/协会分成。客单低但**流失低**（工具嵌进日常经营） |
| **独占层/护城河** | ①**独占分发**：绑定一个本地渠道（行业协会/SaaS 收银/连锁/本地 KOL）②垂直模板与话术③行业 know-how，通用工具做不细 |
| **最危险假设** | **A3**：能否拿到**独占的本地分发**（这是唯一能防住红海和后端的东西）；产品本身不难 |
| **最便宜实验** | 谈 1 个本地渠道伙伴（一家连锁/一个协会/一个收银 SaaS），拿 10 个商家做 concierge，看他们用了之后是否续用 + 渠道方是否愿意共推 |
| **成功阈值** | ≥1 个渠道方口头愿意共推；10 家里 ≥5 家用后说「会继续用」 |
| **周期** | 4–6 周（成败在能否谈下渠道，非技术） |
| **主要风险** | ①单垂直天花板低，需可复制到多垂直②本地地推重、慢③抖音/点评官方工具下沉 |
| **谁已在做** | 相对**最不拥挤**（通用工具多，垂直+独占分发少）——这是它的机会 |

**评分**：需求 3 ｜ 差异化 4 ｜ 独占分发 5 ｜ 单元经济 3 ｜ 抗吃掉 4 ｜ 可行性 3 → **加权 3.7**

## 横向汇总与排序

| 维度（权重） | A 电商广告 | B Faceless | C 虚拟人 | D 本地垂直 |
|---|---|---|---|---|
| 需求/付费意愿（0.20） | 5 | 4 | 4 | 3 |
| 差异化空间（0.15） | 2 | 2 | 3 | 4 |
| 独占分发（0.20） | 3 | 3 | 3 | 5 |
| 单元经济（0.15） | 4 | 2 | 5 | 3 |
| 抗后端吃掉（0.15） | 3 | 2 | 3 | 4 |
| 启动可行性（0.15） | 3 | 5 | 3 | 3 |
| **加权总分** | **3.40** | **2.90** | **3.50** | **3.70** |

### 研判（创业者口径）
- **D（本地垂直）总分最高**，胜在**独占分发 + 差异化 + 抗被吃**——这三点恰是调研 §7 结论最看重的（模型商品化后，护城河只能在分发/数据/know-how）。代价是需要地推、天花板需靠复制多垂直打开。
- **C（虚拟人）单元经济最好、B2B 留存好**，但正面撞 HeyGen/Synthesia 强品牌，且质量门槛（口型/一致性）最硬。
- **A（电商广告）需求最强但最拥挤**，且直接暴露在「FAL 客户即可上游做」的风险下。
- **B（Faceless）最好启动但最不该做**：红海 + 低客单 + 高流失 + 护城河最薄，容易变成给别人打样。

### 建议的下注方式
不要一次押满。**先花 1–2 周做「渠道可得性」这一个致命验证**：
- 对 **D**：能不能谈下 1 个本地渠道伙伴共推？（这是 D 唯一的生死点）
- 对 **C**：能不能锁定 1 个愿意盲评的 B2B 垂直？
谁先在「最危险假设」上给出正向信号，就把 Cycle 2 的 concierge MVP 押给谁。**C 和 D 是第一梯队，A 次之，B 暂缓。**

> 下一步：选定 1–2 个进入 Cycle 2 后，把该场景的 VH/BH 具体化，设计 concierge MVP 的执行清单与度量看板，并回填到 `lean-spec.md` 的决策日志。
