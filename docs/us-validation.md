> 目标：只做应用层、只在美国、把「AI 版 VTuber」这个方向做一次**能落地、花得起、结论清晰**的验证。
> 配套：`realtime-plays.md`（战略）、`lean-spec.md`（假设登记表）、`demo/`（可跑的 API demo）。

## 1. P1 / P2 / P3 不是三个赌注，是一台引擎的三种变现

先回答你的问题：**一、二、三（P1 AI VTuber / P2 陪伴关系 / P3 品牌定制频道）能不能拼成一个商业模式？** 能——而且它们本来就是**同一台引擎**（固定人格 + 实时 AI 视频 + 社群）被**三种方式变现、按风险顺序展开**：

```
                    ┌─────────────────────────────────────────┐
                    │   同一台引擎：人格 + 实时AI视频 + 社群      │
                    └─────────────────────────────────────────┘
                          │              │               │
              ┌───────────┘      ┌───────┘        ┌──────┘
              ▼                   ▼                ▼
   P1 AI VTuber            P2 陪伴/关系          P3 品牌/IP 定制频道
   ─────────────          ────────────         ──────────────────
   消费级楔子·顶端漏斗       高 ARPU 变现           B2B 放大·高客单
   免费公开·蹭热点获客       同一人格的深度关系       给品牌做专属 AI 主播
   打赏+订阅起量           订阅+高价私密档          定制费+月度托管
   （拉新 & 验证人格）      （已被相邻赛道验证）      （绕开大众亏损）
```

**为什么这个顺序对（从验证角度）**：
- **P1 是楔子**：用一个公开的 AI VTuber 低成本拉新、并验证最危险的假设「人格能否留住人」。它同时是 P2/P3 的**获客口和活体 demo**。
- **P2 是变现主力**：把 P1 留下的人，导流到「与这个人格的深度/私密关系」——这是美国**唯一已跑通订阅**的高 ARPU 出口（companion 2022→2025 增长 ~700%）。P1 免费、P2 收钱。
- **P3 是放大器**：等引擎跑通，把「做一个会带货的人格 AI 主播」的能力打包卖给品牌（B2B 定制 + 月费），客单最高、绕开免费大众流的结构性亏损。

**一句话商业模式**：`用免费的 AI VTuber(P1) 拉新并证明人格 → 把粉丝转化为付费的陪伴/会员关系(P2) → 把整套人格引擎作为服务卖给品牌(P3)`。三者共用人格资产、社群、技术栈，**验证一个就为下一个铺路**，不是三线作战。

**美国市场对齐（钱袋子，C7）**：美国=**订阅 + 打赏 + 品牌**。所以变现主力放 P2 订阅（不是中国式打赏带货），P1 用 Twitch subs/bits、TikTok/YouTube 的 gifts/superchat 起量，P3 走 B2B。

## 2. 关键成本纪律：不要做 24/7 连续流

Infinite Slop 的教训（C9）：**24/7 连续生成 = 结构性亏损**（一条流零售等值 ~$4k/天）。验证阶段**绝不能这么烧**。改成：

| 反模式（会烧死） | 我们的做法（验证阶段） |
|---|---|
| 24/7 连续生成 | **定时开播**：每天 1 场 30–60 分钟直播 |
| 每秒都在生成新画面 | **事件驱动生成**：只在有弹幕/打赏/剧情节点时生成一段 5s 片，其余时间循环待机动画/上一段 |
| 768P 追清晰 | **480P**（$0.05/秒）验证够用，slop 本来就不追画质 |
| 全 AI 自动导演 | **concierge（人肉导演）**：我们真人在后台挑弹幕、定节奏、控人设——验证阶段用人补 AI 的不足 |

> 核心洞察：验证「人格能否留住人」**不需要无限视频**，只需要「**一个有记忆、会实时回应你的固定人格**」。视频是躯壳，留人的是人格 + 互动。

- 保守按每场 1 小时、~$45–60/场（含重试）。

| 档 | 周期 | 直播场次 | 算力(fal) | 语音TTS | 拉新广告 | 工具/杂项 | **合计** | 能得到的结论 |

| **A 极简验证** | 2 周 | 14 场 × 30 分 | ~$300 | $22 | $300 | ~$80 | **~$700–1,000** | 人格有没有回头客（RA-1 方向性信号） |

## 4. 怎么验证（US、2 周 A 档执行清单）

**最危险假设 RA-1（先验这个）**：美国观众会对一个 **AI 人格** 产生准社会依恋、持续回访。

**平台选择（美国）**：
- **TikTok Live**：发现流量最强、gifts 变现，但要 1000 粉门槛 + 审核严（AI 内容标注）。
- **Twitch**：subs/bits 成熟、社群黏性强，但 AI 内容政策风险要盯。
- **YouTube Live**：superchat + 发现 + 可留存回放做拉新。
- **A 档建议**：主攻 **1 个平台**（YouTube Live 或 Twitch，门槛低、可回放），少量广告导流，别分散。

**执行步骤**：
1. **定人格**（1 天）：给 AI 主播一个固定名字、外形、世界观、口头禅、记忆设定（例：一个爱吐槽科技新闻的赛博猫主播）。人格是留人的锚，先定死。
2. **搭最小管线**（2–3 天）：`弹幕/聊天 → 人肉挑选+改写 prompt → fal H3 Max 生成 5s 片 → OBS 推流 → TTS 配音`。用我们已写好的 `demo/`（API 已打通）做生成核心。待机时循环一段固定动画。
3. **定时开播**（2 周 × 每天 30 分）：固定时段（培养「事件感」，对抗 Clubhouse 式同步负担 C4）。人肉导演控节奏、回熟客、点名感谢（即时反馈回路 C2）。
4. **埋点度量**（贯穿）。

**成功阈值（RA-1）**：

| 指标 | 阈值 | 怎么测 |
|---|---|---|
| **次日/隔场回访率** | ≥15% | 平台分析后台 / 熟客 ID 追踪 |
| 平均观看时长 | ≥5 分钟 | 平台后台 |
| 弹幕互动率（发言观众/总观众） | ≥10% | 手动统计 |
| **自发的社群行为** | 出现取名、玩梗、追问剧情、「昨天那只猫呢」 | 定性观察（最强信号） |
| 关注/订阅转化 | ≥3% | 平台后台 |

**判定**：达阈值 → 人格留人假设成立，进 Cycle 3 验 RA-2（付费）；不达 → 换人格类型或转向 P2（陪伴，需求已验证、更直接）。

**RA-2（下一轮，B/C 档）**：留下的人愿为「与这个人格的深度关系/会员」付费。最便宜实验：加最小订阅/打赏解锁互动，测付费率与 ARPPU。
