## 五个核心问题的结论

1. **核心区别** — 不是更强的模型，而是「在开源权重上做全栈推理优化，用 延迟×价格 竞争」：5 秒 768p 片 ~3 秒出片（快于实时），$0.08/秒。
2. **第一性原理** — 开源权重抽掉了训练收租人；FAL 的比较优势是推理而非预训练；「快于实时」是产品体验的相变阈值；后训练是通往前沿画质的廉价捷径；768p 天花板就是速度的代价。
3. **舆情与生态** — 为速度叫好、对「#1」存疑；病毒点是 Infinite Slop 无限直播（但需 FAL 赞助算力）。已证实的 FAL 客户：Poe、Hedra、Canva、Perplexity、Krea、Freepik 等。
4. **商业模式** — 按量付费的生成媒体推理引擎，18 个月冲到 ~$100M ARR，估值 $4.5B。军火商正在向下游抢生意。
5. **成本盈亏** — 满价单条几乎稳赚（基准毛利 ~92%，最悲观仍 ~56%）；免费额度与 5 折是可算账的获客补贴，不是亏本倾销。

> 免责声明：调研截至 2026-09-04。FAL 官方数字（35×/#1/<3s）尚无独立验证，报告中已作「待验证假设」处理并与第三方数据分离。
